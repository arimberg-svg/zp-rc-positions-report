# ЗП РЦ по должностям (авг 2025 — июл 2026)

Обезличенный отчёт по начислениям зарплаты отдела складской и транспортной логистики («У Михалыча»).

**Интерактивный отчёт:** откройте [index.html](index.html) (GitHub Pages) или скачайте репозиторий и откройте файл локально.

## Что внутри

| Файл | Содержание |
|---|---|
| `index.html` | Графики и таблицы |
| `report_data.json` | Агрегированные данные без ФИО |
| `build_report.py` | Скрипт пересборки (нужны исходные ведомости и табели локально) |

## Ключевые выводы

- **Средняя ЗП за период:** ~58 600 ₽ (медиана ~61 700 ₽)
- **Пиковый месяц:** **май 2026** — средняя **66 829 ₽**
- **Минимальный месяц:** октябрь 2025 — средняя 51 532 ₽
- **Выше всех по средней:** менеджер по логистике (~73 900 ₽)
- **Кладовщик:** ~60 300 ₽, пик тоже в мае 2026 (~70 500 ₽)

## Ограничения отчёта

- ФИО и табельные номера **не публикуются**
- Должность **руководитель РЦ и логистики** исключена
- Должности взяты из табелей Т-13 (сопоставление по таб. номеру выполняется только при сборке)
- В публичном репозитории только агрегаты — исходные ведомости с персональными данными не включены
