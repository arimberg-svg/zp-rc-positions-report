# ЗП РЦ по должностям (авг 2025 — июл 2026)

Обезличенный отчёт по начислениям зарплаты отдела складской и транспортной логистики («У Михалыча»).

**Интерактивный отчёт:** [общий](https://arimberg-svg.github.io/zp-rc-positions-report/) · [кладовщики мин/макс](https://arimberg-svg.github.io/zp-rc-positions-report/kladovshchiki.html)

## Что внутри

| Файл | Содержание |
|---|---|
| `index.html` | Общий отчёт по должностям |
| `kladovshchiki.html` | Отдельный отчёт по ЗП кладовщиков (мин / макс) |
| `report_data.json` | Агрегаты по должностям без ФИО |
| `kladovshchiki_data.json` | Мин/макс/распределение по кладовщикам |
| `build_report.py` | Скрипт пересборки |

## Кладовщики: планка ЗП

- **Минимум за период:** 4 000 ₽
- **Максимум за период:** 96 750 ₽
- **Средняя / медиана:** ~60 300 ₽ / ~64 200 ₽
- **34** человека, **150** чел.-мес.

## Ограничения отчёта

- ФИО и табельные номера **не публикуются**
- Должность **руководитель РЦ и логистики** исключена
- Должности взяты из табелей Т-13 (сопоставление по таб. номеру выполняется только при сборке)
- В публичном репозитории только агрегаты — исходные ведомости с персональными данными не включены
